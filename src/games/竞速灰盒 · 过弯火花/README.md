# 竞速灰盒 · 过弯火花（竞争强化版）

## 怎么玩

**双击 `index.html`** 用浏览器打开就能玩。不用安装、不用联网、不用账号。

1. 开始面板按 `1`–`4` 或点击卡片选一台载具（四台都会上场：你选 1 台，另外 3 台是电脑对手）。
2. 按 `Enter` 或点「开始比赛」。
3. 一局 **220 秒 / 4200 米**，跑到终点或时间到时按进度排名次。

| 按键 | 作用 |
|---|---|
| `↑` / `W` | 油门 |
| `↓` / `S` | 刹车 |
| `←` `→` / `A` `D` | 转向（急弯全速会蹭墙掉速，松油门或朝弯心打方向） |
| 鼠标左键 / `空格` | 发射道具 |
| `Q` | 主动技能（各载具不同，带 CD） |
| `P` | 暂停　`H` | 说明　`D` | 调试面板　`R` | 结算后再来一局 |

> `D` 单击会开调试面板、按住仍是右转；想完全避开就用 `←` `→` 转向。

## 这版改了什么（让它更有竞争欲）

- **AI 先让后追**：开局你领先；赛程过 18% 后三台电脑按各自节奏逐步提速，中段一点点贴上来，后段**真的会超到你前面**；但领先太多会收油，你全力跑或用冲刺还能抢回来。
- **和自己的最好成绩比**：每局结束自动保存你最好的那次跑法。下一局赛道上会多一台**半透明紫色虚线的幽灵车**（你的历史最佳），它不碰撞、不占名次，HUD 实时显示「与最佳 ↑快 / ↓慢 几秒」。
- **看得见的输赢**：右上大字 `P1/4` 名次、与前车米差，左上「最佳完赛成绩」，结算页有评级 S/A/B、★新纪录、本局用时和「再来一局」。
- **公平可复现**：AI 加压是确定性曲线，不靠随机抖动，同一局重跑结果一致。

## 成绩存在哪

存在你自己浏览器的本地存储里（键 `ghost_v1`）。不联网、不上传、无账号；换浏览器或清缓存会清空。

## 已知未做（本轮档位：基本可玩）

- 没有起跑 3-2-1 倒计时；这是 **4200m 单程抵达赛**，没有「圈 / 圈速」概念。
- 没有「最近 5 次成绩列表」和「12 段分段对比条」——列为下一版候选。
- 音效默认关闭，开始面板可点「音效：开」打开；浏览器要求首次交互后才出声。
- 灰盒画面（色块 + 线条），不是最终美术；无移动端 / 手柄输入。
- 验收脚本里 C11–C19 共 9 条「接线齐全度自检」字段未接入，属工具层，不影响游玩（详见 `docs/验收报告-v1.md`）。

## 目录

| 路径 | 内容 |
|---|---|
